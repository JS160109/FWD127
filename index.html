About the Project

What is SysGrid?

A web page made with HTML, CSS and basic JavaScript to show computer lab workstation allocation and a session register.

Problems it addresses

  • Showing which workstations are reported faulty
  • Seeing which students used which PCs
  • Filtering the register by subject
  • Adding a new session without editing the code
