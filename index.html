About the Project

What is SysGrid?

A simple web page made with HTML and CSS to show computer lab workstation allocation and a sample session register.

Problems it addresses

  • Showing which workstations are reported faulty
  • Seeing which students used which PCs in the sample register
  • Filtering the register by subject
